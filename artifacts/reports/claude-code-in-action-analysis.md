## 核心知识点

### 1. 上下文管理
- 添加上下文 (Adding Context)
- 控制上下文 (Controlling Context)
- 理解 Claude Code 如何理解你的代码库

### 2. 自定义与扩展
- 自定义命令 (Custom Commands)
- MCP 服务器集成
- Claude Code SDK 使用

### 3. Hooks 机制
- Hooks 的概念与定义
- 实现自定义 Hook
- 常见问题与最佳实践
- 实用 Hook 示例

### 4. 工具集成
- GitHub 集成
- 与现有开发工作流结合
